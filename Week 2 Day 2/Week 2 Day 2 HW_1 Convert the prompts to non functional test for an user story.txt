Test Case: Login Page Load Time

Description: Verify that the login page loads within an acceptable time frame.
Preconditions: User navigates to the ticket booking application's login page.
Test Steps:

Measure the time taken for the login page to fully load (including all elements like user ID field, password field, and login button).

Test Case: Login Response Time

Description: Verify that the login process completes within an acceptable time frame after submitting valid credentials.
Preconditions: User is on the login page with valid credentials entered.
Test Steps:

Enter valid user ID and password.
Click the "Login" button.
Measure the time taken from clicking the login button to receiving the login confirmation or dashboard page load.


Expected Result: The login process should complete within 5 seconds under normal network conditions.
Non-Functional Aspect: Performance (Response Time)

Description: Verify that the application supports multiple users logging in simultaneously without performance degradation.
